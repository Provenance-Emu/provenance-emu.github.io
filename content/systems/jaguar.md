Atari's Jaguar was the company's last home console, launched in 1993 and marketed as the first "64-bit" system. Its library is small but has a devoted following, with standout titles like Tempest 2000, Alien vs Predator, and Iron Soldier. {{< brand >}}Provenance{{< /brand >}} emulates the Jaguar, including Jaguar CD titles, through the Virtual Jaguar core.

{{< family-app app="jaguar" text="Virtual Jaguar libretro is the core that powers this emulation, and it has its own site with detailed compatibility and performance data." >}}

## Supported File Formats

- `.j64` — Standard Jaguar cartridge ROM format
- `.jag` — Alternative Jaguar cartridge ROM extension
- `.rom` — Generic ROM extension used by some Jaguar dumps
- `.abs` — Jaguar executable/homebrew format
- `.cof` — Jaguar COFF executable format
- `.bin` — Raw binary cartridge dump
- `.prg` — Jaguar program/homebrew format
- `.cdi` / `.cue` — Jaguar CD disc images, supported where the underlying core provides Jaguar CD emulation

## BIOS
