App Store

Recommended

The easiest way. Automatic updates, no computer needed. Provenance is 100% free on the App Store.

  • Works on iPhone, iPad, and Apple TV
  • Automatic updates via the App Store
  • Optional Provenance Plus for iCloud sync & priority support

AltStore

Sideload directly via AltStore. Tap "Add Source" to add the Provenance source, then install from the Browse tab.

  • Requires AltStore on your iPhone/iPad and AltServer on your Mac or PC
  • Refresh every 7 days (or use AltStore PAL on EU devices — no refresh needed)
  • Source URL: https://provenance-emu.com/apps.json

SideStore

Sideload wirelessly without a computer using SideStore. Tap "Add Source" to add Provenance.

  • Fully on-device — no Mac or PC required after initial setup
  • Refresh every 7 days using SideStore's built-in VPN trick
  • Source URL: https://provenance-emu.com/apps.json

Download the latest IPA and sideload manually, or build Provenance yourself from the open-source code.

What's New in 3.3.0

This is a big one. Four months of work since 3.2.1 covering iCloud sync, a completely revamped tvOS interface, video filters, and a ton of core and stability fixes.

☁️ iCloud / CloudKit Sync

  • ROMs, save states, BIOS files, and artwork now sync across devices via iCloud
  • Real-time download progress indicators when loading cloud save states
  • Auto BIOS sync on game load when available in iCloud
  • ROM metadata syncs alongside files
  • Artwork syncs after library updates
  • CloudKit records management tab in Settings
  • iCloud upsell UI for new users with empty libraries
  • Sync queue pauses during emulation and resumes after

📺 New tvOS UI (Default)

  • Completely redesigned tvOS interface now enabled by default
  • RetroWave-themed side menu with smooth animations
  • Save states browser accessible from the main UI with artwork and core name
  • "View All" saves section with per-system filtering
  • TopShelf v2: recent games and save states with artwork and timestamps
  • Cheats UI in the pause menu
  • Game "More Info" panel
  • Log viewer tab
  • Import status view in side menu
  • Search with persistent history
  • Dozens of focus, navigation, and theming fixes throughout

🎨 Video Filters & Shaders

  • Unified filter pipeline works across native and RetroArch cores
  • GB and VHS filters improved
  • Filters accessible from the pause menu
  • RetroArch GLES 3D cores now supported (Vecx/GLiden, etc.)
  • Dolphin shader/filter support
  • PPSSPP filter support

🎮 Core & Controller Fixes

  • RetroArch: Fixed player index mapping for MFi, PS4, and Xbox controllers; PS4 start/select fixed; 32x controls added; GameCube controller responder added
  • Mupen64Plus: Fixed PS4 start button; fixed tvOS scaling and placement; better save error messages
  • Dolphin: Fixed Vulkan landscape rendering
  • GenPluGX: Added CHD support; added wide-screen GameGear core
  • PicoDrive: Fixed crash on unload; fixed 32x controller mapping
  • FCEUmm: Fixed start/select button mapping
  • Mednafen: Fixed DualShock/DualSense pause/play button mapping
  • GameBatte / TGDB Dual: Fixed PSX/Xbox pause/select button mapping

🐛 Bug Fixes & Stability

  • Fixed multiple app hangs from main-thread Realm access (moved to background)
  • Fixed crash in pause menu when closing core
  • Fixed potential crash if audio ring buffer init fails
  • Fixed crash in share/import extension
  • Fixed aspect ratio issues in Stella and some other cores
  • Fixed FPS label appearing in screenshots
  • Fixed artwork not refreshing in game library after sync
  • Fixed game importer re-queuing already-imported items
  • Fixed Realm contentless core crash
  • Fixed "Continue" carousel metadata mismatch
  • Skin selector refreshes orientation previews on rotation change
  • ManicSkin/DeltaSkin files can now be opened directly from Safari
  • iPad import status modal clipped layout fixed
  • DSP audio engine fixes

⚡ Performance

  • Artwork loading significantly faster
  • Game library UI rendering optimizations (removed unnecessary Observable wrappers)
  • Async tab bar icon loading
  • CloudKit sync deduplication and repeat-lookup fixes
  • Game importer skips MD5 hashing for large non-BIOS files

Homebrew (macOS)

Install the stable standalone app from the project tap:

brew tap Provenance-Emu/virtualjaguar
brew trust --cask Provenance-Emu/virtualjaguar/virtualjaguar
brew install --cask Provenance-Emu/virtualjaguar/virtualjaguar

Raspberry Pi: use a 64-bit OS for the ARM64 app. Installation, bundled shader runtime and graphics requirements. Per-SoC core builds are separate downloads; a 64-bit CPU running a 32-bit OS needs a 32-bit core.

The app patches cartridges with IPS files, browses RomM servers and server add-ons, and gains a debugger loop for writing your own Jaguar code. Windows downloads are Authenticode-signed for the first time.

Release fixes

  • The Windows x64 app detects ARM64 emulation and limits Mesa software rendering to its SSE2 CPU path. This fixes an illegal-instruction crash during startup on Windows ARM while preserving user-supplied Mesa CPU settings (#1221).
  • Signature verification consumes the complete certificate report. A valid DLL with a long timestamp report now passes the release verifier (#1221).
  • Linked and grouped Emulation Server downloads preserve the server's selected launch entry and retrieve the files required by the selected group (#1220).
  • Release CI retains verified build and test checkpoints for unchanged inputs. Windows signing can reuse unsigned install trees, and signature verification can run directly against an existing staged release. Failed shader shards retain their passing preset results and retry remaining presets. The first timeout of a macOS preset gets a separate serial retry with both logs kept (#1221).

Library and patches

  • Open or drop an .ips patch. Choose the base cartridge from the library, the running game or a file; the dialog shows the base and patched SHA-256 values and can check them against expected ones. Boot the patched cartridge from memory, save it as a separate copy, or replace the original after a byte-for-byte recovery copy has been written. Saves and states of a patched game are kept apart from the original's. Copies can be saved to FAT32 and exFAT drives too (#1208).
  • Server libraries are named tabs, each with its own address, sign-in, search and artwork. A RomM 5.4 server can be browsed directly, alongside Emulation Server (#1209).
  • Selecting a server game lists its add-ons. Downloads are checked against the server's size and SHA-256 when it gives them. A cartridge IPS add-on can be launched straight away; other formats are download-only (#1216).

Debugger

For homebrew, the Tools menu now covers the edit, build and debug loop (docs/app-debug-tools.md, "Homebrew workflow") (#1218):

  • Break at start halts every load and every Reset at the 68000's first instruction, so breakpoints can be set before anything runs.
  • Reloading the program you are working on keeps its breakpoints, and each one follows the label it was set on to its address in the new build. The CPU debugger, memory viewer and Symbols windows stay open.
  • Reload when the file changes loads a rebuild by itself.
  • One memory watchpoint: a byte range, reads and/or writes. It sees 68000 accesses only; a write by the GPU, DSP or blitter does not trigger it.
  • With symbols loaded, the CPU debugger labels its listing, names labelled operands, takes a symbol in Go to, and the halt bar says where it stopped.
  • From a build script: virtualjaguar --break-at-boot --reload-on-change --break main --watch score:2:w game.cof

The GDB stub's watchpoints (Z2/Z3/Z4) now honour the requested length and trigger on any overlapping 68000 access. Before, only an access at exactly the watched address did.

Signing and verification

  • Windows app packages, installers, core DLLs and tools are signed with Azure Artifact Signing, and the release gate verifies each one against Microsoft's root with a verified timestamp (#1150, #1200). The v3.12.0 Windows downloads remain unsigned.
  • SHA256SUMS.txt is minisign-signed and AppImages carry an embedded GPG signature. The public keys are in docs/ and the minisign key is pinned in both install scripts (#1199).
  • A stable release is published only after the exact staged Windows installers have been installed, booted and uninstalled on native x64, native ARM64 and x64 under ARM emulation (#1210).
  • The per-artifact verification table attached to the release is the authority for what each file's signature state is.

Graphics and startup

  • An animated initialization screen accompanies graphics qualification before the main window opens. Windows can select the bundled software OpenGL path when the system driver is insufficient (#1183).
  • Fix bundled Mesa shutdown hangs and repeated-start problems on Windows (#1167).
  • The mild vj-scanlines preset is enabled when no shader choice was saved. Existing choices remain intact; a failed default filter leaves the plain picture usable. --shader NAME|FILE|off overrides the filter for one run (#1159).
  • Windows x64 and ARM64 use a shader runtime built from pinned source instead of the upstream DLL with additional legacy DirectX dependencies (#1161).
  • ARM64 Flatpak packages now include the shader runtime (#1168).

Cheats and library

  • Select labeled cheat values from a dropdown, edit numeric values, and choose from small explicit ranges. Apply once writes the value without leaving a per-frame freeze enabled (#1186).
  • RetroAchievements hardcore restrictions still apply. Queued cheat commands use an atomic permission flag to avoid a race with the UI policy (#1190).
  • Browse and launch games from an Emulation Server in the library (#1188).
  • Correct the Mac App Store library build configuration for persistent bookmarks, and improve font-worker validation (#1176, #1175).

Picture

  • The picture now covers the whole visible line, so games no longer lose columns at the left edge. The standard NTSC frame grows from 326 to 352 pixels wide (345 on PAL), and columns past a game's display end show the border color, as on hardware. Screenshots and windows use the wider frame (#1191).

Debugger

  • Tools > Symbols lists the names and hex values from a .cof or .abs file, with search and a breakpoint checkbox on each row (#1195).

Packaging and verification

Cloud tests exercise windowed OpenGL startup and bundled shader presets on Windows x64/ARM64, Linux and macOS. Release packaging also checks the Windows portable ZIP and installed application. Download verification uses build provenance and the per-artifact verification table attached to the release. Compatibility and limitations

The 155-title cartridge and 28-case CD boot sweeps have no backward moves from 3.11.0. The accurate-blitter cartridge sweep matches the default sweep's boot stages and watchdog results. Gorf 2000 reaches game code in both HLE and real-BIOS boot modes.

Core options and v17 savestates carry over from 3.11.0. RISC pipeline measurement tests were added without changing the timing model (#1158).

macOS OpenGL stops at 4.1: presets requiring unsupported features are refused. Complex CRT presets may be too slow on software rendering; the default filter is deliberately lightweight. On Windows ARM64, use the ARM64 package; native ARM64 testing does not establish compatibility of every x64 graphics component under Windows emulation.
